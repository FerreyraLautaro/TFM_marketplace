Marketplace Demo

API:
Sesión: sin sesión
Swagger (/docs)

Cada paso llama a la API real de este servidor. Se muestran la petición, el código de estado y la respuesta.

1Registrar un comprador

Crea un usuario nuevo con rol BUYER. El comprador de prueba comprador@example.com ya existe en la base.

2Login del comprador

Obtiene el JWT y consulta GET /auth/me con él.

3Elegir productos

Catálogo público. Se preseleccionan productos de varios vendedores para que la orden se divida.

4Crear la orden

Una orden con una suborder por vendedor; cada suborder copia la comisión de su vendedor.

5Iniciar el pago

El pago es asíncrono: queda PENDING hasta que el proveedor confirme por webhook.

6Autorizar el pago (checkout simulado)

El proveedor simulado firma un evento payment.updated y lo entrega por el mismo camino que el webhook real.

7El vendedor despacha su suborder

Cada vendedor ve solo sus suborders y las avanza: PENDING → ACCEPTED → SHIPPED → DELIVERED.

8Normalizar un título con IA

Como vendedor, propone marca, nombre, cantidad, unidad y categoría. Llama a Gemini: puede tardar unos segundos o responder 503 si el modelo no está disponible.
